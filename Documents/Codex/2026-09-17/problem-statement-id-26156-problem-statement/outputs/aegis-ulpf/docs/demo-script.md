# Two-minute live demonstration

The included 60-second MP4 is a screenshot walkthrough of actual UI states, with selectable English captions and no audio. Enable captions in the video player. For a live evaluation, rehearse this sequence with synthetic replay clearly visible, or substitute a verified device feed.

| Time | Screen / action | Say |
|---|---|---|
| 0–15s | Command center; Launch demo | “LOGFLUX receives heterogeneous perimeter logs, stores their original bytes first, and creates a common representation. These records are labeled synthetic.” |
| 15–30s | Sources, then an event | “The collector accepts TCP, UDP and optional verified TLS. Source, transport and receipt time stay attached to the evidence.” |
| 30–50s | Parser lab, unfamiliar router | “Unknown structure enters review. A local model can suggest fields, but a deterministic validator rejects unsupported meanings.” |
| 50–70s | Semantic assertions, validate, approve | “Our labeled sample tells us which address is source and destination. Validation runs inside a bounded WASM mapping runtime. The reviewed parser is signed and versioned.” |
| 70–85s | Replay and event comparison | “Replay creates a new normalized revision. The original bytes and hash remain unchanged.” |
| 85–100s | Verify evidence | “We check the byte hash, manifest and Merkle inclusion path against a quorum-signed checkpoint. These three witnesses are local in this prototype.” |
| 100–115s | Investigation and export | “Analysts follow observations into an evidence case and export JSONL, ECS or CSV. HTTP delivery retries use the same delivery ID.” |
| 115–120s | Return to command center | “The single-node prototype is measured and reproducible. Device certification and distributed billion-event scaling are the next validation stages.” |

A practical live run should use a prepared candidate so model latency does not consume the two-minute slot. Never imply the prerecorded screenshots show a physical firewall or a real attack.
